# 💼 Salary Increase Calculator

## 📌 Descrição
Aplicação web desenvolvida para simular o cálculo de aumento salarial com base no tempo de empresa.  
O projeto foi criado com foco em praticar conceitos fundamentais de HTML, CSS e JavaScript.

---

## 🛠 Tecnologias utilizadas
- HTML5 (estrutura e semântica)
- CSS3 (layout com flexbox, box-model e estilização)
- JavaScript (manipulação do DOM, lógica de cálculo e operadores)

---

## 🚀 Funcionalidades
- Entrada de dados via formulário (nome, salário e tempo de empresa)
- Cálculo automático do percentual de aumento
- Exibição do novo salário formatado em moeda (BRL)
- Interface simples e intuitiva

## 💡 Regras de negócio
- Até 3 anos: 5% de aumento  
- De 3 a 10 anos: 10% de aumento  
- Acima de 10 anos: 15% de aumento  

---

## 📚 Aprendizados
Neste projeto pratiquei:
- Estruturação semântica com HTML  
- Organização de layout com CSS (Flexbox)  
- Integração entre HTML e JavaScript  
- Manipulação de inputs e eventos  
- Uso de operadores condicionais (ternário)
